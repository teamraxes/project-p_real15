  1. phase 01

    Brief

    brief.json · 30 мин · Telegram

    30-минутный разговор в TG. Не «brand workshop», не «discovery session». Один диалог, в котором мы заполняем структурированную форму.

    Что спрашиваем: ниша и стадия бизнеса, целевая аудитория одним абзацем, ключевое сообщение, 3 главных оффера, 3 нет-слова, конкуренты, дедлайн.

    Что не спрашиваем: ваши «ценности», «миссия», палитру эмоций, цвет дивана в офисе. Это есть в Notion-шаблонах рекламных агентств — не у нас.

    • На выходе — brief.json (схема Layer 1–4)
    • Если затягиваем — ниже 25 минут редко бывает; если ниша новая — до 45.
    30 мин1 артефакт
    brief.json

  1. phase 02

    Research

    niche_intel.md · 3 ч · Claude + ручная фильтрация

    Конвейер собирает niche-intelligence: визуальный ландшафт ниши (топ-15 конкурентов), визуальные тропы которые повторяются, и недоиспользованные направления.

    Дальше дизайнер вручную фильтрует. AI пишет первую гипотезу — «в нише AI-стартапов перегружены тёмные градиенты, попробуем cream-canvas». Человек подтверждает или отбраковывает.

    • Источники — Awwwards, Mobbin, Land-book, плюс прямой обход URL.
    • Что отдаём — короткий PDF: 5 «избегать», 3 «попробовать», 1 invariant.
    3 ч1 артефакт
    niche_intel.md
  2. phase 03

    Synthesizer

    style_vector + sitemap · 2 ч

    Шесть осей style-dimensions: formality, density, decoration, energy, era, color-temperature. Каждая ось получает значение 0–1 с обоснованием.

    Из вектора собираются: палитра (один accent), пара шрифтов, sitemap (страницы + секции), бриф под каждое изображение и видео.

    • Артефакты — composition.json, creative_direction.json, image_briefs.json, video_briefs.json
    • Подпись — дизайнер апрувит вектор до того как пишется код.
    2 ч4 артефакта
    + Arbiter review
  1. phase 04

    Stagehand

    HTML / CSS · 10–14 ч · production-grade

    Семантический HTML5 (header / main / footer / nav / article). CSS без Tailwind, токены из дизайн-системы. WCAG 2.4.7 focus-visible на каждом интерактивном элементе.

    Mobile-first responsive на 320 / 768 / 1024 / 1440. Tap-targets ≥ 44×44. Lighthouse mobile ≥ 95 — это hard-gate перед deploy.

    • Деплой-target — Vercel или Timeweb (российский хостинг)
    • Code review — обязательно вторым человеком, перед production push
    10–14 чN HTML
    + styles.css
  2. phase 05

    Downstream

    media · copy-pass · QA · deploy

    Генерация картинок по image_briefs.json (gpt-image-1, warm-graded, single-red anchor). Видео — либо seedance, либо CSS-animation fallback по solo brief.

    Финальный copy-pass с редактором: убираем «хайп», проверяем что нет stock-фраз. QA-гейты — A11y, Lighthouse, broken-link scan. Push в production.

    • QA-гейты — QG-005 focus-visible, QG-008 mobile reflow, QG-009 reduced-motion
    • Handoff — короткий loom на 10 минут, как редактировать в CMS
    4 чdeploy
    + handoff
